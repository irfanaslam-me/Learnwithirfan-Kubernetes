# How to Install Kubernetes on Windows

This guide sets up a local Kubernetes cluster on **Windows** using Minikube and kubectl.

---

## What You Need Before Starting

1. **Windows 10 or Windows 11**
2. **Chocolatey** — a package manager for Windows (like apt on Linux)
3. **Docker Desktop** — must be installed and running

> Minikube uses Docker to create the cluster on your machine.

---

## Step 1 — Install Chocolatey (if not already installed)

Open **PowerShell as Administrator** and run:

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
[System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072
iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
```

Verify it worked:
```powershell
choco --version
```

---

## Step 2 — Install kubectl

`kubectl` is the command-line tool you use to talk to Kubernetes.

```powershell
choco install kubernetes-cli -y
```

Check the installation:
```powershell
kubectl version --client
```

You should see something like:
```
Client Version: v1.x.x
```

---

## Step 3 — Install Minikube

Minikube creates a Kubernetes cluster on your local machine.

```powershell
choco install minikube -y
```

Check the installation:
```powershell
minikube version
```

---

## Step 4 — Start Docker Desktop

Before starting Minikube, make sure **Docker Desktop is running**.

You can check by looking at the system tray — Docker shows a whale icon when it is running.

---

## Step 5 — Start Your Kubernetes Cluster

```powershell
minikube start --driver=docker
```

This will take a few minutes the first time. It downloads the Minikube image and sets up the cluster.

When done you will see:
```
✅  Done! kubectl is now configured to use "minikube" cluster
```

---

## Step 6 — Verify Everything is Working

```powershell
kubectl cluster-info
```
```
Kubernetes control plane is running at https://127.0.0.1:XXXXX
```

```powershell
kubectl get nodes
```
```
NAME       STATUS   ROLES           AGE   VERSION
minikube   Ready    control-plane   1m    v1.xx.x
```

If you see `Ready` — your cluster is running and ready to use.

---

## Useful Minikube Commands

| Command | What it does |
|---------|-------------|
| `minikube start` | Start the cluster |
| `minikube stop` | Stop the cluster (saves your work) |
| `minikube delete` | Delete the cluster completely |
| `minikube status` | Check if the cluster is running |
| `minikube dashboard` | Open the Kubernetes web dashboard in your browser |

---

## Common Problems & Fixes

**Problem: Docker is not running**
```
❌ Exiting due to PROVIDER_DOCKER_NOT_RUNNING
```
Fix: Open Docker Desktop and wait for it to fully start. Then run `minikube start` again.

**Problem: Old cluster is broken**
```bash
minikube delete
minikube start --driver=docker
```
This deletes the old cluster and creates a fresh one.
